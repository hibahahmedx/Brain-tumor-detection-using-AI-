# Brain-tumor-detection-using-AI-
This folder contains code for brain tumor detection using yolov11
Introduction: brain tumor is one of the most leading fatal diseases that is related to the neurology of a human. In order to provide a timely treatment for it, it needs to be diagnosed as early as possible. There are manual ways through which a tumor can be detected by viewing the MRI images. But this method is time taking, requires professionals (doctors, nurses) to handle the detection and most importantly since it is handled by humans, it is prone to human error which very often leads to misdiagnosis or false diagnosis. To solve this issue, I have created an AI model that is trained on 1956 images of three different types of brain tumors using yolov11 pre-trained model. After that I have integrated the trained model with a web application that I have created using flask. 
Dataset: the dataset was obtained from universe roboflow website. The dataset contains 1956 total MRI images of 3 different types of brain tumors; glioma, meningioma, pitutuary gland tumor and brain images with no tumor. The dataset is split into three sections; testing, training and validation. The testing dataset contains 1370 images, the testing dataset contains 395 images and the validation dataset contains 191 images. The dataset contained images along with their annotations which are required by computer vision algorithms like yolov11 to be able to detect objects. 
YOLOv11: yolov11 is the latest iteration of the computer vision model YOLO (you only look once). YOLOv11 provides Detect, Segment, and Pose models pre-trained on the COCO dataset, as well as Classify models pre-trained on the ImageNet dataset. Track mode is also available for all Detect, Segment, and Pose models. I have used this model because it is the best choice for my requirements since I have to make detection of tumors from image inputs and it is widely used for object detection. 
Flask application: I have made a simple web application of this model on flask which is a library on python that provides variety of options to create a web application specifically of machine learning models. I have also used html backend programming as index.html and results.html file. The static file contained all kinds of fonts and styling of the website
